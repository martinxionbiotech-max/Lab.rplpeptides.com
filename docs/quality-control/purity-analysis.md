# Purity Analysis

## HPLC Purity and Impurity Profiling

## Purity Reporting

Purity is reported as the area percentage of the main peak at 214 nm UV detection.

---

## Impurity Types

| Impurity Type | Source | HPLC Profile |
|---|---|---|
| Deletion sequences | Incomplete coupling | Earlier eluting |
| Truncated peptides | Failed deprotection | Earlier eluting |
| D-isomers | Racemization | Co-eluting or shoulder |
| Dimer/aggregates | Over-coupling | Later eluting |
| Scavenger residues | Cleavage | Early eluting |

---

## Acceptance Criteria

| Application | Purity Standard |
|---|---|
| Research use | ≥95% |
| In vivo studies | ≥98% |
| Clinical trials | ≥98% (GMP) |
| Diagnostic use | ≥98% |
| Custom requirement | Per specification |
