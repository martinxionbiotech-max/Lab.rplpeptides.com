# HPLC Method Validation

## Analytical Method Validation for Peptide Testing

## Purpose

Validated analytical methods ensure reliable, reproducible, and accurate peptide purity determination.

---

## ICH Q2(R1) Validation Parameters

| Parameter | Definition | Acceptance Criteria |
|---|---|---|
| **Specificity** | Method distinguishes target from impurities | Baseline separation |
| **Linearity** | Response proportional to concentration | R² ≥ 0.999 |
| **Range** | Concentration range with acceptable accuracy | 50–150% of target |
| **Accuracy** | Closeness to true value | Recovery 98–102% |
| **Precision** | Repeatability of results | RSD ≤ 2.0% |
| **Intermediate Precision** | Day-to-day/analyst-to-analyst variation | RSD ≤ 2.0% |
| **Detection Limit (LOD)** | Minimum detectable analyte | S/N ≥ 3:1 |
| **Quantitation Limit (LOQ)** | Minimum quantifiable analyte | S/N ≥ 10:1 |
| **Robustness** | Insensitivity to method variations | Within specification |

---

## Acceptance Criteria for Peptide HPLC Methods

| Validation Parameter | Research Method | GMP Method |
|---|---|---|
| Linearity (R²) | ≥ 0.995 | ≥ 0.999 |
| Precision (%RSD) | ≤ 3.0% | ≤ 2.0% |
| LOD | ≤ 0.1% | ≤ 0.05% |
| LOQ | ≤ 0.5% | ≤ 0.2% |
| Recovery | 97–103% | 98–102% |
