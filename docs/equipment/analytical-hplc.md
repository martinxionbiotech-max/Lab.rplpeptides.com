# Analytical HPLC System

## Peptide Purity Analysis

## Category
Analysis Equipment

## Application
Purity determination, method development, and quality control

## Function
Quantify peptide purity and identify impurities in crude and purified samples.

---

## Key Parameters

| Parameter | Typical Range |
|---|---|
| Flow rate | 0.5–2.0 mL/min |
| Column ID | 2.1–4.6 mm |
| Column length | 50–250 mm |
| Particle size | 3–5 μm |
| Max pressure | 400–1000 bar |
| Detection | UV-Vis, DAD (diode array) |

---

## Column Selection

| Column Type | Application |
|---|---|
| C18 (most common) | General peptide analysis |
| C8 | More hydrophobic peptides |
| C4 | Large peptides and proteins |
| Phenyl | Alternative selectivity |

---

## Method Parameters

| Parameter | Typical Value |
|---|---|
| Temperature | 25–40 °C |
| Gradient slope | 1–2% B/min |
| Runtime | 20–40 minutes |
| Detection | 214 nm (primary), 254 nm, 280 nm |
