# Peptide Synthesizer


## TL;DR

Automated peptide synthesizers handle couplings, deprotections, and washes with precision. Scale ranges from 0.1 mmol to 10 mmol per run, with options for microwave assistance.

## Category
Synthesis Equipment

## Application
Automated Fmoc or Boc solid-phase peptide synthesis

## Description
Peptide synthesizers automate the repetitive steps of SPPS — deprotection, washing, coupling, and monitoring. They range from research-scale bench-top instruments to large-scale production systems.

---

## Types of Synthesizers

| Type | Capacity | Features |
|---|---|---|
| Bench-top | 0.05–5 mmol | Compact, single or multiple vessels |
| Mid-scale | 5–50 mmol | Larger vessels, automated reagent handling |
| Process-scale | 50–500 mmol | Full automation, GMP-compliant |
| Microwave | 0.1–5 mmol | Microwave-assisted coupling, reduced cycle time |

---

## Key Parameters

| Parameter | Typical Range |
|---|---|
| Scale per batch | 0.1–500 mmol |
| Number of vessels | 1–4 (parallel) |
| Cycle time per AA | 30–90 min (conventional), 5–15 min (microwave) |
| Solvent consumption | 10–50 mL/g resin |
| Temperature control | RT to 80 °C |
| Mixing | Nitrogen bubbling, shaking, or mechanical |

---

## Related Process Steps

- Resin loading
- Fmoc deprotection
- Amino acid coupling
- Wash cycles

---

## Automation Benefits

- Reproducible coupling conditions
- Reduced operator error
- Automated monitoring (UV, temperature)
- Overnight unattended operation
- GMP data logging
