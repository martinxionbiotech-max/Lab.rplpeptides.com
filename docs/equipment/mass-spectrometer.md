# Mass Spectrometer

## Peptide Mass Analysis

## Category
Analysis Equipment

## Application
Molecular weight confirmation and structural characterization

## Function
Provides accurate molecular weight measurement of intact peptides and fragments.

---

## Ionization Methods

| Method | Peptide MW Range | Features |
|---|---|---|
| ESI (standard) | 500–6000 Da | Most common, multiply charged |
| MALDI-TOF | 500–50,000 Da | High mass range, single charge |
| Direct infusion | 500–6000 Da | No LC coupling, fast analysis |

---

## Analyzer Types

| Type | Resolution | Application |
|---|---|---|
| Quadrupole | Unit | Routine MS, quantitation |
| TOF (time-of-flight) | High | Accurate mass, intact MW |
| Ion trap | Unit | Fragmentation, structural analysis |
| Q-TOF | High | Accurate mass + fragmentation |

---

## Key Specifications

| Parameter | Typical Value |
|---|---|
| Mass accuracy (TOF) | <5 ppm |
| Resolution (TOF) | 10,000–50,000 FWHM |
| Scan speed | >10 spectra/s |
| Sensitivity | femtomole level |
