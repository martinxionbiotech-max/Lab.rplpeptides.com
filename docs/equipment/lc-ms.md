# LC-MS System

## Liquid Chromatography-Mass Spectrometry

## Category
Analysis Equipment

## Application
Identity confirmation and purity assessment

## Function
Combines HPLC separation with mass detection for molecular weight confirmation of peptide peaks.

---

## Key Parameters

| Parameter | Typical Range |
|---|---|
| Mass range (m/z) | 100–3000 (standard), up to 6000 (extended) |
| Resolution | Unit resolution (standard quadrupole) |
| Ionization | ESI (electrospray ionization) |
| Detection modes | Full scan, SIM, MRM |

---

## LC-MS Workflow

1. HPLC separates peptide components
2. ESI ionizes peptide molecules
3. Mass analyzer measures m/z
4. Software deconvolutes to calculate molecular weight

---

## Typical Results

| Measurement | Expected |
|---|---|
| Mass accuracy | ±0.5 Da |
| Match to theoretical | ±1 Da (confirms identity) |
| Adducts | Na⁺, K⁺, TFA adducts common |
