# Reactor System

## Large-Scale Synthesis Vessels

## Category
Synthesis Equipment

## Application
Large-scale peptide SPPS and solution-phase reactions

## Function
Provide controlled environment for chemical reactions with temperature, mixing, and pressure control.

---

## Key Parameters

| Parameter | Typical Range |
|---|---|
| Vessel volume | 1–200 L |
| Material | Glass (borosilicate), stainless steel |
| Temperature range | -10 to +100 °C |
| Mixing | Mechanical stirrer or overhead agitator |
| Jacketed | Temperature control via circulating fluid |
| Pressure | Atmospheric (SPPS), up to 5 bar (some processes) |

---

## Types

| Type | Material | Application |
|---|---|---|
| Glass reactor | Borosilicate | Lab to pilot scale |
| Stainless steel | 316L SS | Production scale, GMP |
| Double-jacketed | Glass or SS | Precise temperature control |

---

## Features

- Inlet ports for reagents and nitrogen
- Bottom drain valve
- Sampling port
- Temperature probe
- Reflux condenser (for solution-phase)
