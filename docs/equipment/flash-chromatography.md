# Flash Chromatography

## Rapid Peptide Purification

## Category
Purification Equipment

## Application
Initial purification of crude peptide, desalting

## Function
Fast, lower-resolution purification using C18 silica under pressure.

---

## Key Parameters

| Parameter | Typical Range |
|---|---|
| Column size | 5–100 g silica |
| Flow rate | 10–100 mL/min |
| Particle size | 20–40 μm |
| Pressure | 5–20 bar |

---

## Advantages

- Faster than preparative HPLC
- Lower solvent consumption
- Good for initial purity upgrade (60% → 85%)

## Limitations

- Lower resolution than HPLC
- Higher product loss
- Not suitable for final purification to ≥98%
