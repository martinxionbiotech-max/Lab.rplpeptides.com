# Wang Resin

## Standard Solid Support for SPPS

## Definition

Wang resin is a crosslinked polystyrene bead with p-alkoxybenzyl alcohol linkers. It is the most common resin for Fmoc-SPPS producing C-terminal carboxylic acid peptides.

---

## Specifications

| Parameter | Typical Value |
|---|---|
| Base polymer | Crosslinked polystyrene (1% DVB) |
| Bead size | 100–200 mesh (75–150 μm) |
| Loading | 0.3–1.0 mmol/g |
| Linker | p-Alkoxybenzyl alcohol |
| Swelling (DMF) | 4–6 mL/g |
| Swelling (DCM) | 6–8 mL/g |

---

## Key Properties

| Property | Importance |
|---|---|
| Mechanical stability | Resists deformation during mixing |
| Chemical stability | Stable to TFA during SPPS cycles |
| Swelling | Good swelling in DMF and DCM |
| Loading uniformity | Consistent coupling kinetics |
| Cost | Economical for most applications |

---

## Cleavage

- **Reagent**: TFA (50–95%)
- **Product**: Peptide with C-terminal carboxylic acid
- **Time**: 1.5–4 hours at room temperature

---

## What Are the Applications of Wang Resin?

| Application | Suitability |
|---|---|
| Standard peptide synthesis | Excellent |
| Long peptides (>30 AA) | Good (may need low loading) |
| Peptide acids | Excellent |
| Industrial scale | Preferred choice |
