# Acetonitrile

## HPLC Mobile Phase Solvent

## Definition

Acetonitrile (MeCN) is the primary organic solvent used as mobile phase B in peptide HPLC purification and analysis.

---

## Specifications

| Parameter | Typical Value |
|---|---|
| Purity | ≥99.9% (HPLC grade) |
| UV cutoff | 190 nm |
| Water content | ≤0.02% |
| Grade | HPLC gradient grade |

---

## Role in Peptide Analysis

| Function | Detail |
|---|---|
| Mobile phase B | Elutes peptides from C18 column |
| Gradient from 5–60% B | Separates peptide from impurities |
| Peptide solubility | Good for most peptides |
| UV transparency | Low UV absorption at 214 nm |
