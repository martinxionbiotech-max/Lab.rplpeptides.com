# HATU — High-Efficiency Coupling Reagent

## For Difficult Peptide Couplings

## Definition

HATU (O-(7-azabenzotriazol-1-yl)-N,N,N',N'-tetramethyluronium hexafluorophosphate) is a high-reactivity coupling reagent for difficult couplings.

---

## Specifications

| Parameter | Typical Value |
|---|---|
| Purity | ≥99% |
| Appearance | White crystalline powder |
| Storage | -20 °C, desiccated |
| CAS number | 148893-10-1 |

---

## When to Use HATU

| Scenario | Recommendation |
|---|---|
| Sterically hindered AAs (Val, Ile, Thr) | HATU recommended |
| His coupling | HATU (lower racemization) |
| Long sequences (>20 AA) | Double coupling + HATU |
| Routine couplings | HBTU sufficient |

---

## Typical Conditions

| Parameter | Value |
|---|---|
| Equivalents | 2.9 eq (relative to AA) |
| Base | DIEA (6 eq) |
| Activation time | 2–3 minutes |
| Coupling time | 30–60 minutes |

---

## Advantages

- Higher coupling efficiency than HBTU
- Lower racemization for sensitive amino acids
- Faster reaction kinetics

## Disadvantages

- Significantly more expensive than HBTU
- Used selectively, not for routine couplings
