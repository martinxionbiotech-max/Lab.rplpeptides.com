# DIC — N,N'-Diisopropylcarbodiimide

## Carbodiimide Coupling Reagent

## Definition

DIC (N,N'-diisopropylcarbodiimide) is a carbodiimide coupling reagent used with an additive (HOBt, HOAt, or Oxyma) for amide bond formation.

---

## Specifications

| Parameter | Typical Value |
|---|---|
| Purity | ≥99% |
| Form | Liquid |
| Storage | 2–8 °C |
| CAS number | 693-13-0 |

---

## Advantages

- Low epimerization (with Oxyma)
- No base required
- Economical at scale
- Good for green chemistry (byproduct is water-soluble)

---

## Typical Conditions

| Parameter | Value |
|---|---|
| Equivalents | 3 eq DIC + 3 eq additive |
| Solvent | DMF or DCM |
| Temperature | RT or 50 °C |
| Time | 30–60 minutes |

---

## Safety Note

DIC is a sensitizer and irritant. Handle in fume hood with appropriate PPE.
