## Process Relevance by Peptide Type

| Peptide Type | Key Process Considerations |
|---|---|
| Linear peptides (<30 AA) | Standard SPPS, straightforward |
| Long peptides (30–50 AA) | Aggregation risk, double coupling |
| Cyclic peptides | Side-chain cyclization after cleavage |
| Disulfide-containing | Oxidative folding, controlled conditions |
| Modified peptides | Special amino acids, post-synthesis modification |
