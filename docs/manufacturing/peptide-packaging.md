# Peptide Packaging Guide

## Containers, Closures, and Labeling

## Vial Types

| Vial Type | Material | Application |
|---|---|---|
| **Type I borosilicate glass** | Glass (USP <660>) | GMP products, lyophilized |
| **Type III soda-lime glass** | Glass | Research peptides |
| **Polypropylene** | Plastic | Low-cost, non-GMP |
| **HDPE** | Plastic | Bulk powder, non-sterile |

### Vial Closure System

| Component | Material | Function |
|---|---|---|
| Stopper | Chlorobutyl rubber | Seal, resealability |
| Flip-off seal | Aluminum + plastic | Tamper evidence |
| Crimp cap | Aluminum | Stopper retention |

---

## Labeling Requirements

### Research Grade
- Product name and sequence
- Net peptide weight
- Purity (HPLC %)
- Storage condition
- Batch number
- Expiry date
- Safety warnings (if applicable)

### GMP Grade (adds)
- Manufacturer address
- Dosage form
- Excipients listed
- Regulatory status
- Barcode/QR code
- Tamper-evident seal indicator

## Packaging Validation

| Test | Purpose | Standard |
|---|---|---|
| Container-closure integrity | Seal check | USP <1207> |
| Leak test | Pressure/vacuum | ASTM |
| Extractables/leachables | Material safety | USP <1663> |
| Moisture vapor transmission | Desiccant protection | USP <671> |
